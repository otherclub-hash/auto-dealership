# Auto Dealership

Flagship white-label dealership web app, built as a live demo for the fictional Lakeshore Auto Family group.

- `docs/` holds the plan: requirements, business model, architecture, the fictional dealer profile, and market evidence.
- `src/config/tenant.ts` holds all dealer-specific content, so a new dealer is a config change, not a rebuild.

## Run locally

```
npm install
npm run dev
```

Deploys automatically on Vercel from `main`.
